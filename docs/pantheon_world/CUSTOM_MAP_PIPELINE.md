# Custom worlds — the pipeline we can actually run

*Audited 2026-09-07: what exists on this machine, not what the internet says
about Quake mapping.*

## What is installed

| tool | state |

`q3map2.h` includes `png.h`, and `inout.c` wants libxml2, so a build needs
libpng + zlib + libxml2 for MinGW. That is an ordinary build task and it is
the only thing between us and compiled custom maps.

## Route A — geometry as MD3, no map compiler *(recommended for Phase 2)*

The native host already registers models by path and places them with a
transform — that is exactly what the shot script's `model` / `projectile`
keywords do. A PANTHEON door leaf, banner, plinth or glyph can be an `.md3`
placed inside an existing BSP.

```
PANTHEON parametric geometry (Python) → .md3 writer → shot script
    → pantheon_frame.exe → frames
```

* **needs:** an MD3 *writer*. We have a reader (`creative_suite/api/md3.py`);
  MD3 is a small, documented triangle format with a frame table.
* **gives:** custom geometry inside a real Quake world, today, no new installs.
* **does not give:** collision, lightmaps, `func_door` entities, PVS. Set
  dressing and hero props only.

## Route B — a real compiled map *(Phase 3, for functional doors)*

```
.map text (PANTHEON emits it — brushes are plain text)
    → q3map2 -bsp -vis -light → maps/pantheon_temple_v1.bsp
    → zzz_pantheon.pk3 (ENG-2 naming) → pantheon_frame.exe --game
```

* **needs:** q3map2 built from the vendored source (libpng, zlib, libxml2).
* **gives:** the real thing — brush geometry, lightmaps, `func_door`
  submodels, collision, PVS.
* **note:** `game_quakelive.h` means q3map2 already carries the QL surface and
  content flags. We are not porting a game profile.

## Route C — Blender

Blocked on Blender not being installed. When it exists it feeds **both**
routes: `.ase`/`.obj` → q3map2 `misc_model`, or a direct `.md3` export.

## Rules that apply whichever route

* Steam paks stay read-only (ENG-4). Our content ships as `zzz_*.pk3` (ENG-2),
  and pack testing needs `sv_pure 0` (ENG-3).
* Nothing generated by diffusion becomes geometry or a position. ComfyUI is
  look development, never truth.
* Every custom asset carries provenance: who authored it, from what, licence.
